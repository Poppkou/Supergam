# Тень Ассасина

3D-стелс-экшен для Android в духе Assassin's Creed: средневековый город, паркур по крышам, скрытые убийства и 5 сюжетных миссий.

**Готовый APK:** [`release/ShadowAssassin.apk`](release/ShadowAssassin.apk). Скачай его на телефон и установи; Android попросит разрешить установку из неизвестных источников.

## Миссии
1. **Орлиный взгляд** (обучение). Подняться на башню обзора, синхронизироваться, совершить прыжок веры и устранить предателя.
2. **Сборщик налогов**. Убить сборщика на рынке посреди толпы и стражи, затем скрыться от погони.
3. **Письмо тамплиера**. Выследить курьера, незаметно украсть письмо и доставить его в бюро. Если курьер тебя заметит, он побежит в крепость.
4. **Тени на крышах**. Убрать четырёх лучников на крышах, затем капитана стражи.
5. **Великий Магистр**. Проникнуть в крепость (запретная зона), убить Магистра и уйти живым.

Есть и **Свободный город**: нужно синхронизировать все 4 башни обзора.

## Управление (сенсорное)
| Элемент | Действие |
|---|---|
| Левая половина экрана | Плавающий джойстик (отклонишь сильнее — побежишь) |
| Правая половина | Свайп поворачивает камеру |
| **ПАРКУР** (удерживать) | Свободный бег: спринт, автоматическое лазание по стенам, прыжки с края крыш |
| **ПРЫЖОК** | Прыжок. На стене — отскок, на краю балки башни — прыжок веры |
| **КЛИНОК** | Скрытый клинок. Красная подсветка значит, что можно убить с одного удара: со спины, по ничего не подозревающей цели или в прыжке сверху |
| **КОНТР** | Смертельная контратака, пока стражник замахивается (над ним «!») |
| **✦** | Метательный нож в цель перед камерой |
| **ОРЁЛ** | Орлиное зрение: цели и стража видны сквозь стены |
| **СКРЫТ** | Режим скрытности: среди горожан тебя не замечают |
| **ДЕЙСТВИЕ** | Синхронизация, кража, укрыться в стоге сена |

Клавиатура (для отладки в браузере): WASD, мышь, Shift (паркур), Пробел, J/ЛКМ (клинок), K/ПКМ (контр), F, Q, C, E, Esc.

## Устройство
- `app/src/main/assets/`: сама игра (HTML + JavaScript + three.js r150). Всё процедурное, внешних файлов и интернета не нужно.
- `app/src/main/java/.../MainActivity.java`: полноэкранный WebView в горизонтальной ориентации.

Игру можно открыть и в браузере: `app/src/main/assets/index.html`.

## Сборка
```
export ANDROID_HOME=/путь/к/android-sdk
./gradlew assembleRelease
```
APK появится в `app/build/outputs/apk/release/app-release.apk`. Он подписан debug-ключом, чтобы его можно было сразу установить.
